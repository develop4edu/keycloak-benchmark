= D4E Readme

D4E Modifications on the dataset provider is to add defined realm-roles to generated users.
The custom dataset provider needs to be built and deployed to the Keycloak server.
The dataset provider is a Keycloak add-on that can create entities in a Keycloak data store to prepare it for a load test.

The users can be generated by calling the
`/realms/master/dataset/create-users` endpoint of the Keycloak server.

parameters:

- realm-name=ekv
- count=1000
- user-prefix=loadtest- (optional, default: user-)
- d4e-realm-roles=ekv-benutzer,ekv-kunde,ekv-lehrer (optional, default: empty)

[source]
----
curl "local.klett-werkstatt.de:58080/realms/master/dataset/create-users?count=10&realm-name=ekv&user-prefix=loadtest-&d4e-realm-roles=ekv-benutzer,ekv-kunde,ekv-lehrer"
----
